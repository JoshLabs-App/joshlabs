概述

JOSH本机资源负载（JOSH System Load）由 Joshua Zeng（JoshLabs，加拿大，官网 https://joshlabs.app）开发。本软件是一款运行于 macOS 本机的硬件负载可视化与全球网络连接管控工具，无需注册账号，无广告、无行为追踪。

本机硬件与进程数据

CPU、GPU、统一内存、Swap、磁盘吞吐及进程列表均通过 macOS Darwin / Mach / IOKit 系统接口在您的设备本机实时读取并展示。您的进程清单、命令行参数、内存占用与使用习惯绝不会上传至 JoshLabs 服务器或任何第三方。

全球网络地图与归属地解析

当您查看「全球网络与禁访问」页面时，应用通过 macOS 系统自带工具读取本机当前活跃公网套接字的目标 IP 与实时字节吞吐。为在世界地图上绘制航线坐标与国家城市，应用仅将公网远端目标 IP 发送至公共 GeoIP 地理定位接口查询经纬度与自治系统机构名称，并将解析结果缓存在本机应用支持目录（~/Library/Application Support/app.joshlabs.macpulse/），不包含任何应用名称、进程信息或个人身份信息。

进程清理与系统级禁访问权限

终止进程（释放内存）仅对您主动点击确认的目标生效；执行「深度清缓存（purge）」或「禁访问（写入受管 /etc/hosts 段落与 /etc/pf.anchors/com.joshlabs.macpulse 防火墙锚点）」时，macOS 会弹出系统标准管理员授权框，仅在您本人授权后在本机执行，且随时可一键恢复全部访问限制。

静默前端更新检查

应用启动时会向 https://joshlabs.app/josh-load/ui-manifest.json 检查是否有经过 SHA-256 校验的前端界面增量更新包，该请求不携带任何用户标识或设备遥测数据。

Overview

JOSH System Load (JOSH本机资源负载) is developed by Joshua Zeng (JoshLabs, Canada · https://joshlabs.app). It is a native macOS system load cockpit and outbound network firewall utility. No account is required, and there are no ads or analytics trackers.

Local Hardware & Process Telemetry

CPU, GPU, unified memory, swap, disk I/O, and process metrics are read directly on your Mac via Darwin, Mach, and IOKit APIs. Your process list, memory usage, and command-line metadata never leave your Mac.

World Map & GeoIP Lookup

To render live flight arcs on the World Map tab, public destination IP addresses of active sockets are resolved against public GeoIP lookup endpoints to obtain city/country coordinates and ASN organization names, then cached locally on your Mac. Neither app names nor personal identifiers are transmitted.

Process Termination & Firewall Controls

Memory reclamation and firewall blocking (managed entries in /etc/hosts and /etc/pf.anchors/com.joshlabs.macpulse) run strictly locally on your Mac when triggered by you, using standard macOS administrator authorization prompts when system-level changes are requested.
